# Motion Reference Findings

The supplied reference presents a dark, high-contrast product interface that uses deliberate scene changes rather than constant ornamental movement. Its useful transferable principles are restrained cinematic pacing, large interface zones that reveal in sequence, focused progress-like transitions, and a clear shift between overview and detail states.

Heatcheck will not reproduce the reference’s green-neon palette, trading-interface assets, typography, or layout. Instead, the website will translate the interaction language into its existing Thermal Cartography system: mineral ground, basalt chapters, solar-orange signals, and field-report typography. Motion will rely on short opacity and transform transitions, staggered section reveals, directional layer shifts, and structured active-state indicators. All non-essential movement will respect `prefers-reduced-motion`.
