# Motion and Intelligence Refinement Plan

## Original Motion System

Heatcheck will use a **Field Signal Sequence** rather than reproducing the supplied reference. The experience will progress through calm-to-active states: a clipped headline reveal, a measured scan-line entrance, sequential data-layer activation, and a compact response handoff. This keeps the original Thermal Cartography identity intact while giving the page a more deliberate cinematic rhythm.

The system uses short transform and opacity transitions, staggered by 60–90 milliseconds. Interactive elements will respond with restrained elevation, image drift, and active scan indicators. Large visual shifts are limited to page entry and key section transitions; navigation and frequent controls remain quick. Every non-essential animation will be disabled or simplified under `prefers-reduced-motion`.

## Intelligence Page Hierarchy

The Intelligence page will be reorganized as a five-step operational sequence rather than a flat grid. It will introduce the reading, then present an indexed layer navigator and focused active-layer panel. The five layers will group into three practical stages: **Detect** (thermal and environmental context), **Interpret** (decision engine), and **Respond** (autonomous response and urban context). The lower section will retain a concise evidence-to-action bridge.

## Authenticated Return Path

The signed-in dashboard shell will surface a visible **View public site** control in both the desktop sidebar and mobile header. The control is a standard route link to `/`, so it remains available without ending the authenticated session.

## Validation Record

The Field Signal implementation was validated through a rendered public-page review and an automated contract test that confirms the staged reveal, spotlight transition, and reduced-motion override are present. Selecting the **Decision engine** layer in the rendered Intelligence page updated the spotlight reading from the initial thermal layer to the decision layer. The mobile layer navigator was revised to a fully visible stacked list after responsive review. The signed-in return-to-home flow was confirmed by the user after testing the exposed control across the available dashboard layouts.
